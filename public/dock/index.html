คู่มือการใช้งาน

YouTube Live Chat Overlay · โปรแกรม + OBS + FAQ

ภาพรวม เริ่มต้นใช้งาน แดชบอร์ด เชื่อมต่อ YouTube Overlay คืออะไร ตั้งค่า OBS OBS + TTS เสียงขึ้นไลฟ์ ข้อความไฮไลท์ TTS อ่านออกเสียง คำถามที่พบบ่อย แก้ปัญหา รายการ URL

ภาพรวม

โปรแกรมนี้ดึงแชทจาก YouTube Live มาแสดงบน OBS แบบโปร่งใส และมีระบบไฮไลท์ข้อความ + อ่านออกเสียง (TTS) สำหรับสมาชิก / Super Chat

  • Launcher — เปิดโปรแกรม เช็คอัปเดต แล้วกดเริ่ม
  • Dashboard (Dock) — หน้าควบคุมที่เบราว์เซอร์ http://localhost:43123/dock
  • Overlay — หน้าสำหรับใส่ใน OBS เป็น Browser Source

Port เริ่มต้น: 43123 (แอป) · Launcher: 43124

เริ่มต้นใช้งาน

  1. ติดตั้งจาก GitHub Releases (YouTubeLiveChat-Setup-x.x.x.exe)
  2. ถ้าเคยติดใน Program Files เวอร์ชันเก่า ให้ถอนการติดตั้งก่อน แล้วติดใหม่ (ติดตั้งในโฟลเดอร์ผู้ใช้)
  3. เปิด YouTube Live Chat Overlay จาก Desktop
  4. รอสถานะอัปเดตเป็นเวอร์ชันล่าสุด → กด เริ่มโปรแกรม
  5. เบราว์เซอร์จะเปิด Dashboard อัตโนมัติ
  6. วางลิงก์ไลฟ์ / ช่อง YouTube แล้วกดบันทึก
  7. ตั้งค่า Browser Source ใน OBS ตามหมวด “ตั้งค่า OBS”
ช่องต้องกำลังไลฟ์อยู่ ถึงจะมีแชทไหล — ถ้าไลฟ์จบแล้ว สถานะจะไม่ live

แดชบอร์ด (Dock)

หน้าที่ใช้ควบคุมระหว่างไลฟ์

  • ไฟสถานะมุมบน — WS / Chat / Scroll / Featured / TTS ติด = เชื่อมต่อแล้ว
  • รายการแชท — คลิกข้อความเพื่อขึ้น Featured overlay
  • ค้นหา / แท็บกรอง — กรองสมาชิก Super Chat
  • คีย์ลัด — ↑↓ เลือก · Enter ไฮไลท์ · Esc ล้าง Featured
  • Setup Wizard — ตัวช่วยตั้งค่าครั้งแรก

เชื่อมต่อ YouTube

วิธีง่ายสุด: วางลิงก์ทั้งอันในช่อง “วางลิงก์ YouTube” แล้วกดบันทึก

ลิงก์ตัวอย่างได้ค่า
youtube.com/live/xxxxxLive Video ID
youtube.com/watch?v=xxxxxLive Video ID
youtube.com/@channelHandle
youtube.com/channel/UC...Channel ID

ต้องมีอย่างน้อย 1 ค่า: channelId / liveId / handle

ถ้าใส่แค่ช่อง URL แล้วช่อง Live ID ว่าง — เวอร์ชันใหม่จะแปลงจากลิงก์ให้อัตโนมัติแล้ว
ถ้ายัง error ให้ใส่รหัสหลัง /live/ หรือหลัง v= ในช่อง Live Video ID โดยตรง

Overlay คืออะไร

  • Scroll — แชทไหลด้านข้าง พื้นหลังโปร่งใส
  • Featured — การ์ดข้อความที่คุณเลือกไฮไลท์
  • TTS — แสดงข้อความ + เล่นเสียงอ่าน (สมาชิก / Super Chat)

Overlay ไม่ได้อ่านแชทเอง — ต้องให้โปรแกรมรันอยู่ และ OBS เปิด Browser Source ชี้ URL เหล่านี้

ตั้งค่า OBS (ทีละขั้น)

1) Scrolling Chat

  1. Sources → + → Browser
  2. URL: http://localhost:43123/overlay/scroll
  3. Width 1920 · Height 1080
  4. ติ๊ก Shutdown source when not visible
  5. Custom CSS (ถ้าพื้นหลังดำ):
body { background-color: rgba(0,0,0,0); }

2) Featured Chat

  1. เพิ่ม Browser อีกอัน
  2. URL: http://localhost:43123/overlay/featured
  3. ขนาด 1920×1080 · CSS โปร่งใสเหมือนด้านบน

3) TTS Overlay

  1. เพิ่ม Browser อีกอัน
  2. URL: http://localhost:43123/overlay/tts
  3. ติ๊ก Control audio via OBS (ควบคุมเสียงผ่าน OBS)
  4. ดูหมวดถัดไปเพื่อให้เสียงขึ้นไลฟ์

จัดลำดับ

ลาก Browser ของแชทไว้ บนสุด ในรายการ Sources เพื่อให้ทับเกม/กล้อง

OBS + TTS ให้เสียงขึ้นไลฟ์

  1. Properties ของ Browser TTS → ติ๊ก Control audio via OBS
  2. เมนู แก้ไข → คุณสมบัติเสียงขั้นสูง
  3. แถวเว็บเบราว์เซอร์ TTS ตั้งการมอนิเตอร์เป็น Monitor and Output
    • Monitoring Enabled / Monitor Only = ได้ยินเอง แต่ ไม่ออกไลฟ์
    • Monitor and Output = ได้ยิน + ขึ้นไลฟ์
  4. ติ๊ก Track 1 (แทร็กที่สตรีมใช้)
  5. อย่ามิวต์ใน Mixer

ถ้ามีปุ่มเหลือง “เปิดเสียง” ใน TTS

ใน OBS กดตรงพรีวิวไม่ได้ — ต้อง:

  1. คลิกขวา Browser TTS → Interact
  2. คลิกที่พื้นที่เหลืองในหน้าต่าง Interact
  3. ปิด Interact แล้วทดสอบใหม่

หรือคลิกขวา → Refresh cache of current page หลังอัปเดตโปรแกรม

ข้อความไฮไลท์ (Featured)

  • คลิกข้อความใน Dock → ขึ้นบน Featured overlay
  • กดล้าง / Esc เพื่อเอาออก
  • ย้อนกลับได้จากปุ่มในแถบ Featured
การคลิกไฮไลท์ = แสดงบนจอเท่านั้น ยังไม่อ่าน TTS
TTS อ่านอัตโนมัติเฉพาะสมาชิก / Super Chat (ถ้าเปิดไว้)

TTS อ่านออกเสียง

  1. ใส่ Browser Source TTS ใน OBS
  2. ใน Dock ติ๊ก เปิด TTS อ่านออกเสียง
  3. เลือกประเภท: สมาชิก / Super Chat / สมาชิก+SC
  4. กดปุ่มทดสอบใน Dock เพื่อเช็คเสียง

เวอร์ชันใหม่เล่นเสียงเป็นไฟล์ MP3 จากเซิร์ฟเวอร์ (ใช้กับ OBS ได้ดีกว่า Web Speech เดิม)

ไฟ TTS มุมบนต้องติด = OBS/เบราว์เซอร์เปิดหน้า TTS อยู่

คำถามที่พบบ่อย

channelId / liveId / handle เอาจากไหน?

ไม่ต้องหาเอง — วางลิงก์ YouTube ทั้งอัน ระบบแยกให้ หรือใส่รหัสวิดีโอ 11 ตัวใน Live Video ID

วางลิงก์แล้วขึ้น “ต้องระบุอย่างน้อย 1 ค่า”?

เคยมีบั๊กช่องว่างทับค่าจาก URL — อัปเดตเป็นเวอร์ชันล่าสุด หรือใส่ Live ID โดยตรง เช่น z_FFXCo3W8U

ทำไมบันทึก config ไม่ได้ / เหมือนไม่ทำงาน?

เวอร์ชันเก่ติดตั้งใน Program Files เขียนไฟล์ไม่ได้ — ถอนติดตั้ง แล้วติดตั้งเวอร์ชันใหม่ใน LocalAppData

TTS อ่านแชททั่วไปไหม?

ไม่ — อ่านเฉพาะสมาชิกและ Super Chat ตามที่ติ๊กไว้

ได้ยินในลำโพงแต่ไม่ออกไลฟ์?

ตั้ง Monitoring เป็น Monitor and Output และอย่าใช้ Monitor Only / Monitoring Enabled

ใน Cursor มีเสียง แต่ Chrome/OBS ไม่มี?

อัปเดตเวอร์ชันที่มี MP3 TTS · ใน OBS ใช้ Interact คลิกเปิดเสียงครั้งแรก · Refresh cache

ปุ่มเหลืองใน OBS กดไม่ได้?

ปกติ — ต้องคลิกขวา Browser → Interact แล้วค่อยคลิกในหน้าต่างนั้น
